_Released 2026-04-29 · [GitHub release](https://github.com/rise-deploy/rise/releases/tag/v0.20.1)_

This release focuses on configuration improvements, OAuth fixes, and developer experience enhancements.

## New features

- **Public JSON Schema endpoint for `rise.toml`** — A new endpoint serves the JSON Schema for `rise.toml`, enabling editor autocompletion and validation (#243)
- **`rise.toml` is now deploy-time config** — The configuration is read at deployment time rather than being baked into the project, making it easier to iterate on build/deploy settings (#244)
- **Improved local dev setup** — Pod security disabled by default (needed for Railpack/root builds), and `docker-compose.yaml` now sets a `name` field for cleaner container naming

## Fixes

- **Allow PKCE and client_secret together** for confidential OAuth clients (#245)
- **Enforce environment default/production flag invariants** — Prevents invalid states where multiple environments claim to be the default or production environment (#242)
- **Use hostPort for ingress-nginx** in k3s dev setup, fixing local routing issues (#241)
- **Set fallback value for `environment_ingress_url_template`** — Prevents missing config errors (#236)

## Other

- Added `.gitattributes` for `.sqlx/*.json` files (linguist/diff handling)
- Updated Rust dependencies (patch-level updates for `aws-sdk-kms`, `reqwest`, and others)
- Updated frontend dependency `jose` to v6.2.3
- Documentation: enforced mandatory `cargo fmt` before every commit
