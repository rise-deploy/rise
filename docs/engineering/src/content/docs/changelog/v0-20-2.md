_Released 2026-04-30 · [GitHub release](https://github.com/rise-deploy/rise/releases/tag/v0.20.2)_

Two bug fixes improving OAuth security controls and environment variable handling.

- **OAuth rate limiting is now per-project, per-IP, and configurable** — Rate limiting for OAuth token exchanges is scoped more granularly instead of being global, and can now be tuned via configuration. (#247)
- **Environment variable source display and scoped propagation** — Fixed how environment variable sources are displayed and how environment-scoped variables are propagated to deployments. (#246)
