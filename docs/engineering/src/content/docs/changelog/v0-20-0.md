_Released 2026-04-27 · [GitHub release](https://github.com/rise-deploy/rise/releases/tag/v0.20.0)_

This release introduces first-class environment support, source metadata tracking, and several security and reliability improvements.

- **First-class environments support** — Environments are now a core concept, enabling separate deployment targets (e.g., staging, production) within a single project (#224)
- **Per-environment Kubernetes ServiceAccounts and labels** — Each environment can have its own ServiceAccount and Kubernetes labels for better isolation and RBAC (#227)
- **Source metadata on projects and deployments** — Projects and deployments now track source information (e.g., git repository, commit) for traceability (#229)
- **OAuth rate limiting** — Token, authorize, and callback endpoints are now rate-limited to prevent abuse (#230)

- **Prevent team deletion when team owns projects** — Teams can no longer be deleted if they still own projects, avoiding orphaned resources (#228)

- Updated Rust dependencies (patch versions) (#217)
- Updated npm dependencies (patch versions) (#220)
- Updated Python dependencies: `packaging` to v26.2 (#226), `click` to v8.3.3 (#222)
- Reverted premature version bump to 0.19.4
