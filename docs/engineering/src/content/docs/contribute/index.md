This section covers development of Rise itself. It includes workspace setup, testing, and the architectural decisions that guide the platform.

## Start here

1. Read the [developer guide](/operator-docs/developer-guide/) for the codebase layout and development conventions.
2. Follow [local development](/operator-docs/development/) to run Rise and its supporting services.
3. Use [testing](/operator-docs/testing/) to select and run the checks relevant to a change.

## Architecture decisions

The [architecture decision records](/operator-docs/adr/) explain the permission model, resource families, process topology, deployment backends, and CLI session design.

For the generic resource model and the intended direction for controller-based extensions, see [Resource API](/operator-docs/resources/), which is a work in progress.
