title: "Extensions"
description: Connect application projects to managed databases, object storage, and OAuth providers.
---

Project extensions add managed capabilities to a project, such as databases, object storage, or OAuth providers. Use the integrations enabled by your platform operator and configure their project-level settings in Rise.

## Available extensions

- [AWS RDS Provisioner](aws-rds-provisioner) — managed PostgreSQL on AWS RDS
- [AWS S3 Bucket](aws-s3-bucket) — managed S3 bucket with injected credentials
- [OAuth](oauth) — end-user OAuth 2.0 / OIDC integration
- [Snowflake OAuth Provisioner](snowflake-oauth-provisioner) — automated Snowflake security integration
