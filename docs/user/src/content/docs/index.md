Rise builds and deploys containerized applications. These docs cover configuring a project, deploying changes, and managing application access.

## Before you begin

You need access to a Rise instance and permission to deploy a project. Follow the [CLI installation instructions](/docs/user-guide/getting-started/#installing-the-rise-cli) and [sign in to Rise](/docs/user-guide/authentication/) before creating your first deployment.

## Recommended reading

1. [Your first deployment](/docs/user-guide/getting-started/) — create a project, build an image, and follow a deployment through to a running application.
2. [Project configuration](/docs/user-guide/configuration/) — define build settings, deployment resources, and project defaults in `rise.toml`.
3. [Environments](/docs/user-guide/environments/) — manage production and preview deployments.
4. [Local development](/docs/user-guide/local-development/) — run your application locally with its project configuration.

## Further reading

Use the [guides](/docs/guides/) for CI/CD, build backends, and application authentication. The [reference](/docs/reference/) covers CLI commands and configuration fields. See [extensions](/docs/extensions/) to connect databases, storage, and OAuth providers.
